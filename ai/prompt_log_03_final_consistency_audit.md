## Corrections I made because of the audit
1. **Cap wording.** The prose had described the 20%/40% cap as if it were an explicit constraint on every method. The code actually applies the cap to Minimum Variance and Maximum Sharpe; Equal Weight is below it by construction, and ERC/HRP are not clipped because clipping changes their defining allocation rule. I corrected the report/app/agent notes to say this. I did **not** change the portfolio outputs: realised ERC/HRP weights were already below the same thresholds. The sentiment tilt clips its multiplier but does not impose a final 20% stock cap.
2. **Covariance shrinkage disclosure.** The implementation uses 10% diagonal covariance shrinkage for Minimum Variance, Maximum Sharpe and ERC. I made that explicit in the methodology rather than leaving it only in code.
3. **Bootstrap reproducibility.** The report's robustness check had a saved result table and plotting helper but was not regenerated by `run_part_b.py`. I added a deterministic moving-block bootstrap helper: 21-day contiguous blocks, 2,000 draws, seed 42, with the same resampled date blocks applied to all selected funds in each draw so paired comparisons preserve cross-fund dependence. The pipeline now writes both individual intervals and paired diagnostics.
4. **AI wording.** I changed `CLAUDE.md` so it plainly discloses the late-stage ChatGPT report help already recorded in prompt log 02 instead of using an over-broad sentence that could imply the report was entirely unaided.
