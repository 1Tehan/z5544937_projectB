# CLAUDE.md

## How I used AI
Claude was my main AI tool for Part B. I used it mainly to draft and debug new code and Streamlit scaffolding while keeping my Part A code as the project base.

I made the portfolio rules, modelling choices and implementation constraints myself. I reran the full project on the real course data and verified the outputs before relying on them.

## What Claude helped with
- Part B portfolio and sentiment code
- Streamlit app scaffolding
- no-look-ahead implementation
- optimiser/debugging issues
- required output structure and filenames

## What I checked myself
- real-data rerun and Part A anchors
- rebalance timing and no-look-ahead
- saved performance metrics
- sentiment outputs
- all seven app pages
- final hand-in checks

## Report-stage use
Near the end, I also used ChatGPT to cross-check my report from results and figures that had already been produced. I reviewed the final wording, numerical claims and economic interpretations myself.
